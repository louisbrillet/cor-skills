# COR Skills

COR (CodingOnRails) is a set of Agent Skills that give AI coding agents a structured Think, Research, Plan, Code, Test workflow with recoverable state.

Audience: developers using COR skills with an AI coding agent (Claude Code, GitHub Copilot, Codex), and authors contributing skills to this repository.

- [Tutorials](tutorials/index.md) - learn COR by shipping a first change end to end.
- [How-to guides](how-to/index.md) - recipes for specific goals.
- [Reference](reference/index.md) - every skill, project file, and script.
- [Explanation](explanation/index.md) - why COR works the way it does.
